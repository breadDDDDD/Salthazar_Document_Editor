# DocStudio

**DocStudio is a free program for reading and editing documents, presentations and PDFs on your own computer.**

It combines the everyday parts of **Microsoft Word** (letters, reports, theses), **Microsoft PowerPoint** (slide presentations) and **Adobe Acrobat** (PDF files) in one window.

- **Private:** your files never leave your computer. Nothing is uploaded to the internet.
- **Works offline:** you don't need an internet connection.
- **Free, nothing to install:** it's a single program you double-click.
- **Easy on the eyes:** make everything bigger, switch to dark mode, or use high contrast.

---

## What can I do with it?

### Write and edit documents (like Word)

| File type | What it is |
|---|---|
| **.docx** | Microsoft Word documents |
| **.doc** | Older Word 97-2003 documents (opened, then saved as .docx) |
| **.txt** | Plain text files |
| **.md** | Markdown notes |
| **.html** | Web pages |

Word files keep their look: page size and margins, fonts and sizes, headings, numbered and bulleted lists (including "1.1"-style numbering), line spacing, indents, tables with borders and shading, pictures, headers and footers.

You can:
- Write and change text, and make it **bold**, *italic*, underlined, coloured or highlighted
- Change the font and text size, use headings and titles
- Make bullet lists and numbered lists
- Add tables, pictures, links and page breaks
- Find a word and replace it with another
- Zoom in and out, and see how many words and pages you've written
- Print your document, or save it as a PDF

> **Older .doc files:** DocStudio opens them and saves your changes as a new **.docx** file. The original .doc file is never changed.

### Make and edit presentations (like PowerPoint)

Open **.pptx** files, or start a **Blank presentation** from the Home screen.

You can:
- See every slide as it looks in PowerPoint: backgrounds, logos, pictures, shapes, tables, charts and equations
- Edit text right on the slide (double-click a text box), with fonts, sizes, colours, bullets and numbering
- **Add slides** with a layout (Title Slide, Title and Content, and the presentation's own layouts), **duplicate**, **delete**, **hide**, and **drag slides** into a new order in the slide list on the left
- **Insert** text boxes, shapes (rectangles, ovals, arrows, stars, lines and more), pictures and tables
- **Move, resize and rotate** anything with the mouse; smart guides help you line things up
- Arrange objects: bring to front, send to back, align and distribute
- Change the slide size (16:9 or 4:3) and the background colour
- Write **speaker notes** under each slide
- Use **Slide Sorter** to see all slides at once
- Present a **Slide Show** full screen (**F5** from the start, **Shift + F5** from the current slide)
- Print the slides, or save them as a PDF (one slide per page)

Files saved by DocStudio open normally in PowerPoint.

### View and edit PDFs (like Acrobat)

You can:
- **Read** PDFs, jump between pages, and search for words
- **Add your own text** anywhere on a page
- **Highlight**, **draw** freehand, or add boxes, circles, lines and arrows
- **Cover up** text you want to hide or change ("Whiteout")
- **Add sticky notes**, pictures and stamps (such as "Approved")
- **Sign** a document: draw your signature with the mouse, or type your name
- **Fill in forms**
- **Organise pages:** turn them, delete them, move them around, or take some pages out into a new PDF
- **Combine** several PDFs into one, or split one PDF into separate pages
- **Turn pictures into a PDF** (for example, photos of receipts)
- **Lock a PDF with a password**, or remove a password you know
- Add a **watermark** (such as "DRAFT") and make the file smaller

## Getting started

### 1. Open DocStudio

Double-click **`DocStudio.exe`**. A window opens with the **Home** screen. (DocStudio uses Microsoft Edge or Google Chrome to show its window. You don't need to set anything up.)

> **Tip:** You can also drag any document onto `DocStudio.exe` to open it straight away.

### 2. Choose what to do

| Button | What it does |
|---|---|
| **Blank document** | Starts a blank page to write on |
| **Blank presentation** | Starts a new slide presentation |
| **Open…** | Opens a document, presentation or PDF from your computer |
| **PDF from images** | Puts photos or pictures together into one PDF |
| **Merge PDFs** | Joins several PDFs into one |

Your **recent files** are listed underneath, so you can open them again with one click. You can also **drop a file anywhere** in the DocStudio window to open it.

### 3. Find your way around

- Each open file gets its own **tab** at the top, like in a web browser.
- A **dot (•)** on a tab means you have changes that aren't saved yet.
- Under the tabs is the **ribbon**, split into sections like **Home**, **Insert** and **View**. Click a section name to see its buttons.
- **Not sure what a button does?** Hold the mouse over it and a short explanation (with its keyboard shortcut) appears.
- The bar along the bottom shows the page or slide number, zoom and helpful hints.

### 4. Save your work

Press **Ctrl + S**, or click **Save** in the **File** section. The first time you save a new file, DocStudio asks where to put it and what to call it.

> **Tip:** To save a copy under another name or format, use **Save As** (**Ctrl + Shift + S**).

### 5. Close DocStudio

Just close the window. If you have unsaved changes, DocStudio reminds you first.

## Common tasks, step by step

### Write a letter
1. On the Home screen, click **Blank document** and start typing.
2. To make a title, select the text and click **Title** or **Heading 1**.
3. Press **Ctrl + S** to save it.

### Change a word everywhere in a document
1. Press **Ctrl + H** (or click **Replace**).
2. Type the word to find and the word to replace it with, then click **Replace all**.

### Edit a presentation
1. Open the .pptx file. The slides are listed on the left; click one to show it.
2. Double-click a text box to change its text. Press **Esc** when you're done.
3. Click **New Slide** (or press **Ctrl + M**) to add a slide; use the arrow next to it to choose a layout.
4. Use **Insert** to add a text box, shape, picture or table.
5. Drag an object to move it, drag the small squares to resize it, and drag the round handle on top to rotate it.
6. Press **F5** to present, and **Esc** to stop.

### Add text to a PDF
1. Open the PDF and click the **Edit** section.
2. Click **Add text**, click on the page, and type.
3. Press **Esc** when you're done, then **Ctrl + S** to save.

### Change text that's already in a PDF
PDFs don't let you edit their original text directly, so DocStudio uses a simple trick:
1. In **Edit**, choose **Whiteout** and drag a box over the old text to cover it.
2. Choose **Add text** and type the new text on top.

### Sign a PDF
1. Open the PDF, go to **Edit** and click **Sign**.
2. Draw your signature with the mouse (or type your name).
3. Place it on the page, and drag the corner to make it bigger or smaller.

### Remove or rearrange pages in a PDF
1. Small pictures of every page appear on the left. Click a page (hold **Ctrl** to pick several).
2. Go to **Organize** and choose **Rotate**, **Delete**, **Extract**, or move pages up and down. You can also drag the page pictures into a new order.

### Put a password on a PDF
1. Open the PDF and go to **Protect**, click **Set password** and type a password.
2. Save the file.

> **Write the password down somewhere safe.** If you forget it, there's no way to open the file again.

## Making it easier to see and use

Click the **Settings** button in the top-right corner. You can:

- **Make everything bigger:** use the size slider (up to double size).
- **Change the colours:** Light, Dark, or **High contrast**.
- **Use an easier-to-read font:** helpful for people with dyslexia.
- **Turn off animations:** if moving things on screen bother you.

DocStudio also works **fully without a mouse**: **Tab** moves between controls, **Enter** presses a button, **F6** jumps between the ribbon, the page or slide, and the side panels. It works with screen readers.

## Handy keyboard shortcuts

Press **F1** at any time (or click the **?** button) to see the full list.

| Press | To |
|---|---|
| **Ctrl + N** | Start a new document |
| **Ctrl + O** | Open a file |
| **Ctrl + S** | Save |
| **Ctrl + Shift + S** | Save as |
| **Ctrl + W** | Close the current file |
| **Ctrl + Z** / **Ctrl + Y** | Undo / redo |
| **Ctrl + F** | Find a word |
| **Ctrl + P** | Print or save as PDF |
| **Ctrl + Tab** | Switch to the next open file |
| **Alt + Home** | Go back to the Home screen |
| **Esc** | Cancel, or close a pop-up window |

**In documents:** Ctrl + B (bold), Ctrl + I (italic), Ctrl + U (underline), Ctrl + K (add a link), Ctrl + H (find and replace).

**In presentations:** Ctrl + M (new slide), Ctrl + D (duplicate), Delete (remove the selected object or slide), arrow keys (move the selected object; Shift for bigger steps), Tab (select the next object), Enter (edit its text), Ctrl + C / X / V (copy, cut, paste), F5 / Shift + F5 (slide show), B (black screen during a show).

**In PDFs, choose a tool with one key:** **V** select, **T** add text, **H** highlight, **D** draw, **W** whiteout, **N** sticky note, **R** rectangle, **E** ellipse, **L** line, **A** arrow, **S** sign.

## Questions and problems

**Is my information sent anywhere?**
No. Everything happens on your own computer, and DocStudio works without the internet.

**The window didn't open.**
Make sure Microsoft Edge or Google Chrome is installed (Edge comes with Windows). Wait a few seconds and double-click `DocStudio.exe` again.

**My Word document or presentation looks a little different.**
DocStudio keeps fonts, spacing, lists, tables, pictures, headers and footers, and slide layouts. Very unusual content (for example SmartArt, animations or columns of text) is kept in the file but may look simpler on screen. Keep a copy of important originals before editing.

**I opened a .doc file and it saved as .docx.**
That's on purpose: DocStudio reads old Word 97-2003 files but saves in the modern .docx format, leaving your original untouched.

**I can't select or change the original words in a PDF.**
That's normal for PDFs. See *"Change text that's already in a PDF"* above.

**How do I close DocStudio completely?**
Just close the window. DocStudio switches itself off within a few seconds; nothing keeps running in the background.

<details>
<summary><b>For developers (technical details)</b></summary>

DocStudio is written in Go (standard library plus pdfcpu). It runs a small local web server on `127.0.0.1`, which only accepts requests from its own window, and shows its interface in an Edge or Chrome app window. The interface is plain JavaScript with no build step.

**Build:** `go build -ldflags "-H=windowsgui" -o DocStudio.exe .`
**Run with a console for debugging:** `go run . -no-browser -port 8080`, then open http://127.0.0.1:8080
**Test:** `go test ./...`

| Folder / file | Purpose |
|---|---|
| `main.go` | Local server; bundles the `web/` folder into the program |
| `internal/fsapi` | Browse, read and save files |
| `internal/docx` | Word .docx to and from HTML, keeping styles, numbering, tables, images, headers/footers |
| `internal/doc` | Reads binary Word 97-2003 .doc files into the same HTML |
| `internal/pptx` | PowerPoint .pptx to and from a JSON slide model (keeps masters, layouts and untouched shapes) |
| `internal/pdfops` | PDF operations, using [pdfcpu](https://github.com/pdfcpu/pdfcpu) |
| `web/` | Interface: `app.js` (window, tabs, icons, dialogs), `word.js` (document editor), `slides.js` (presentation editor), `pdfeditor.js` (PDF editor), `vendor/pdfjs` (PDF display, pdf.js 3.11.174) |

</details>
